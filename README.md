# Domain lists

`service-catalog.json` — единственный исходный файл проекта.

Каждый сервис описывается один раз и содержит:

- имя и постоянный `id`;
- одну или несколько `memberships`: категорию и полный набор доменов;
- связанные IPv4-списки;
- при необходимости `probeDomains` для проверки доступности.

Текущий маршрут Ethernet/WG не хранится в репозитории: его ведёт Hopper. При
появлении нового сервиса роутер создаёт его DNS-маршруты и начинает с WG1. Новый
dомен существующего сервиса остаётся на маршруте этого сервиса.

Hopper получает этот файл каждые 15 минут. Старые раздельные `data/`, `lists/`,
`data-ipv4/`, `index.json` и `metadata/` удалены, чтобы не было двух источников
правды.
