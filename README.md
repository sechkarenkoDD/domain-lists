# Domain lists: единый каталог

Редактируется только `service-catalog.json`. В нём для каждого сервиса хранятся
категории, связанные домены, IPv4-сети, имя для уведомлений и, при необходимости,
основные адреса проверки. Текущий маршрут Ethernet/WG в этот файл не записывается:
его хранит Hopper.

После изменения запускается:

    node tools/compile-service-catalog.js .

Команда генерирует совместимые файлы `data/`, `data-ipv4/`, `lists/`, `index.json`
и `metadata/services.json`. Их вручную не редактируют.

Новый сервис добавляют как одну запись в `services` с `memberships`. Новый домен
существующего сервиса добавляют в его `memberships[].domains`. Для IPv4 создают или
дополняют запись `ipv4Lists` и указывают её идентификатор в `ipv4Lists` сервиса.

Hopper собирает свой рабочий манифест непосредственно из `service-catalog.json`.
Новый сервис на роутере будет получать начальный маршрут WG1 по отдельному правилу
синхронизации; дальнейшие проверки смогут перенести его между Ethernet и WG1–WG3.
