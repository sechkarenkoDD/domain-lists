## Keenetic

Если репозиторий публичный, URL будет выглядеть так:

```text
https://raw.githubusercontent.com/<owner>/<repo>/main/lists/AI.lst
```

Если репозиторий приватный, роутеру понадобится способ авторизации. Не вставляй GitHub token в URL, если он может попасть в логи или чужие руки.
