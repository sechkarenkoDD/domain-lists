# Совместимый каталог сервисов

`metadata/services.json` генерируется из `../service-catalog.json` командой
`node tools/compile-service-catalog.js .`. Не редактируйте его вручную.

Единый исходный каталог содержит категории, сервисы, домены, IPv4-ресурсы и
настройки проверки. Текущие назначения Ethernet/WG находятся только на Hopper.
